Refresh and publish the Claude usage report. Do exactly these steps, with no extra exploration:

1. Run `__REPO__/claude_usage.py` with Bash. It collects this machine, pulls every machine from the hub, prints a summary, and ends with two lines: `page: <path>` and `artifact: <url or none>`.
2. Read the page file named on the `page:` line. It is generated by the user's own script; the Artifact tool needs it read before publishing.
3. If the `artifact:` line has a URL: call the Artifact tool with `action: "read"` and that `url`, then publish `file_path` = the page with that `url`. Do not pass `icon`.
   If it says `none`: publish `file_path` = the page with `icon: "chart"` and `description: "Claude plan usage since the last reset, by machine, source and hour."`, then run `__REPO__/claude_usage.py config --artifact-url <the new URL>` so later runs update the same link.
4. Reply in a few lines: the link, then each machine's estimate and share from the summary. If a step fails, say which one and show its error.
